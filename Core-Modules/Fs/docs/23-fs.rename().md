# Introduction

`fs.rename()` is the asynchronous version of `fs.renameSync()`.

It can be used to

- Rename files
- Rename directories
- Move files
- Move directories

Unlike `renameSync()`, JavaScript does **not** wait for the operation to finish.

The rename operation runs in the background.

When it finishes, the callback function is executed.

---

# Why rename()?

Suppose a user uploads a file.

```
uploads/

└── 9f31d8.png
```

After processing,

you want to move it into

```
images/

└── profile.png
```

Instead of blocking the server,

Node.js performs the operation asynchronously.

---

# Syntax

```js
fs.rename(oldPath, newPath, callback);
```

---

# Parameters

| Parameter | Description |
|----------|-------------|
| oldPath | Current path |
| newPath | Destination path |
| callback | Function executed after rename completes |

---

# Callback Function

The callback receives one argument.

```js
(error) => {

}
```

If the operation succeeds,

```js
error
```

is

```js
null
```

Otherwise,

it contains an Error object.

---

# Return Value

`fs.rename()` returns

```js
undefined
```

The result is available inside the callback.

---

# Internal Working

```
Application

↓

FS Module

↓

libuv

↓

Operating System

↓

Rename / Move

↓

Callback Queue

↓

Event Loop

↓

Execute Callback
```

JavaScript continues executing while the operating system performs the rename operation.

# Renaming a File

Before

```
project/

└── notes.txt
```

Code

```js
const fs = require("fs");

fs.rename(

    "notes.txt",

    "tasks.txt",

    (error) => {

        if (error) {

            console.log(error);

            return;

        }

        console.log("Renamed");

    }

);
```

project/

└── tasks.txt

# Error Handling

Always check the error first.

```js
const fs = require("fs");

fs.rename(

    "missing.txt",

    "new.txt",

    (error) => {

        if (error) {

            console.log(error.message);

            return;

        }

        console.log("Success");

    }

);
```

---

# Common Error Codes

| Error Code | Meaning |
|------------|---------|
| ENOENT | Source file does not exist |
| EACCES | Permission denied |
| EPERM | Operation not permitted |
| ENOTDIR | Expected a directory |
| EISDIR | Expected a file |
