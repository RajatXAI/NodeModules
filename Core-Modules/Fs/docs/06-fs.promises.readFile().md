# Introduction

Node.js originally provided callback-based APIs such as

```js
fs.readFile()
```

Although these APIs work well, large applications often become difficult to read because callbacks start nesting inside each other.

To solve this problem, Node.js introduced the Promise-based File System API.

Instead of callbacks, it returns a Promise.

This allows us to use modern JavaScript features like

- Promise
- async/await

which makes code cleaner and easier to maintain.

---

# Why fs.promises?

Compare both approaches.

Callback

```js
fs.readFile("data.txt", "utf8", (error, data) => {

    if (error) {

        console.log(error);

        return;

    }

    console.log(data);

});
```

Promise

```js
const data = await fs.readFile(
    "data.txt",
    "utf8"
);

console.log(data);
```

The Promise version is shorter, cleaner and easier to understand.

# Error Handling

Use

```js
try...catch
```

Example

```js
const fs = require("fs").promises;

async function readData() {

    try {

        const data = await fs.readFile(
            "missing.txt",
            "utf8"
        );

        console.log(data);

    } catch (error) {

        console.log(error.message);

    }

}

readData();
```

# Using async/await

Instead of

```js
fs.readFile(..., callback)
```

we write

```js
const file = await fs.readFile(
    "data.txt",
    "utf8"
);
```

This makes asynchronous code look almost like synchronous code while still remaining non-blocking.

# Best Practices

✅ Prefer Promise APIs in modern Node.js projects.

✅ Use async/await instead of deeply nested callbacks.

✅ Always handle errors with try...catch.

✅ Use encoding while reading text files.

---

# Common Mistakes

### Forgetting await

```js
const data = fs.readFile(
    "data.txt",
    "utf8"
);

console.log(data);
```

Output

```
Promise { <pending> }
```

---

### Using await Outside async Function

```js
const data = await fs.readFile(...);
```

This will throw a SyntaxError.

---

### Forgetting Error Handling

Always wrap asynchronous code inside

```js
try...catch
```
