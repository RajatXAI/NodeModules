# Introduction

`fs.promises.writeFile()` is the Promise-based version of `fs.writeFile()`.

Instead of callbacks, it returns a Promise.

This makes it easy to use with `async/await`, resulting in cleaner and more readable code.

It is the recommended way of writing files in modern Node.js applications.

---

# Why fs.promises.writeFile()?

Compare both approaches.

### Callback Style

```js
fs.writeFile("notes.txt", "Hello", (error) => {

    if (error) {

        console.log(error);

        return;

    }

    console.log("Done");

});
```

---

### Promise Style

```js
await fs.writeFile(
    "notes.txt",
    "Hello"
);

console.log("Done");
```

The Promise version is shorter, easier to read and avoids callback nesting.

# Return Value

`fs.promises.writeFile()` returns a Promise.

If the operation succeeds,

the Promise is resolved.

If the operation fails,

the Promise is rejected.

The method itself does not return the written data.

# Creating a New File

```js
const fs = require("fs").promises;

    await fs.writeFile(

        "notes.txt",

        "Learning Node.js"

    );

    console.log("File Created");

}

main();
```

Output

```
File Created
```

A new file named


# Writing JSON Data

```js
const fs = require("fs").promises;

async function main() {

    const user = {

        name: "Rahul",

        age: 22

    };

    await fs.writeFile(

        "user.json",

        JSON.stringify(user, null, 2)

    );

}

main();
```

Created File

```json
{
  "name": "Rahul",
  "age": 22
}
```

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        await fs.writeFile(

            "notes.txt",

            "Hello"

        );

        console.log("Success");

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

# Best Practices

✅ Prefer Promise APIs in modern Node.js applications.

✅ Use `async/await`.

✅ Always use `try...catch`.

✅ Convert JavaScript objects using `JSON.stringify()`.

---

# Common Mistakes

### Forgetting await

```js
fs.writeFile(

    "notes.txt",

    "Hello"

);

console.log("Done");
```

The write operation may still be in progress.

---

### Using await Outside an async Function

```js
await fs.writeFile(...);
```

This throws a SyntaxError.

---

### Forgetting Error Handling

Always wrap file operations inside

```js
try...catch
```

# Key Takeaways

- `fs.promises.writeFile()` is the modern way to write files in Node.js.
- It returns a Promise and works seamlessly with `async/await`.
- It creates a file if it does not exist.
- If the file already exists, its contents are replaced.
- Always handle errors using `try...catch`.
