# Introduction

`fs.promises.readdir()` is the Promise-based version of `fs.readdir()`.

Instead of using callbacks, it returns a Promise.

This allows us to use `async/await`, making the code cleaner and easier to maintain.

It is the recommended approach for modern Node.js applications.

---

# Why fs.promises.readdir()?

Many applications need to display the contents of a folder.

Examples

- Image Gallery
- File Manager
- Download Center
- Backup Viewer
- Log Viewer

Instead of manually checking every file,

Node.js can read the entire directory and return all file names.

# Return Value

Returns a Promise.

When resolved,

it returns an array.

Example

```js
[
    "photo.jpg",
    "video.mp4",
    "resume.pdf"
]
```

If an error occurs,

the Promise is rejected.

# Reading Directory Contents

Project Structure

```
project/

└── uploads/

    ├── image.jpg

    ├── notes.txt

    └── video.mp4
```

Code

```js
const fs = require("fs").promises;

async function main() {

    const files = await fs.readdir("uploads");

    console.log(files);

}

main();
```

Output

```js
[
    "image.jpg",
    "notes.txt",
    "video.mp4"
]
```

# Using withFileTypes

By default,

only names are returned.

If you also need to know whether an item is a file or a folder,

use

```js
withFileTypes: true
```

Example

```js
const fs = require("fs").promises;

async function main() {

    const files = await fs.readdir(

        "uploads",

        {

            withFileTypes: true

        }

    );

    files.forEach((item) => {

        console.log(item.name);

        console.log(item.isFile());

        console.log(item.isDirectory());

    });

}

main();
```

Example Output

```
image.jpg
true
false

profile
false
true
```

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        const files = await fs.readdir(

            "missing"

        );

        console.log(files);

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

Example Output

```
ENOENT: no such file or directory
```

# Best Practices

✅ Use Promise APIs in modern projects.

✅ Handle errors using `try...catch`.

✅ Use `withFileTypes: true` when file information is required.

✅ Validate directory paths before reading.

Use

```js

```

or

```js
item.isDirectory()
```

before processing.

---

### Ignoring Errors

Always handle missing directories and permission errors.
