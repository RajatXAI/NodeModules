# Introduction

`fs.appendFileSync()` is the synchronous version of `fs.appendFile()`.

It appends data to the end of a file and blocks JavaScript execution until the operation is completed.

If the file does not exist, Node.js creates it automatically.

Unlike `writeFileSync()`, it does not replace the existing content.

---

# Why appendFileSync()?

Sometimes we want to preserve existing data and simply add new data at the end.

Examples

- Application logs
- Audit logs
- CLI logs
- Build logs
- Local backup history

In these situations, appending data is more useful than replacing the entire file.

---

# Syntax

```js
fs.appendFileSync(file, data[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| file | File path |
| data | Data to append |
| options | Encoding or configuration |

---

# Return Value

`fs.appendFileSync()` returns

```js
undefined
```

If an error occurs,

Node.js throws an Error.

# Internal Working

Suppose

```js
fs.appendFileSync(
    "server.log",
    "Server Started\n"
);
```

Execution Flow

```
Application

↓

FS Module

↓

Operating System

↓

Open File

↓

Move Cursor To End

↓

Write Data

↓

Close File

↓

Continue Execution
```

JavaScript waits until the append operation is completed.

# Creating a New File

If the file does not exist,

Node.js automatically creates it.

```js

fs.appendFileSync(

    "notes.txt",

    "Hello Node.js\n"
```

# Writing JSON Logs

```js
const fs = require("fs");

const log = {

    event: "LOGIN",

    user: "Rahul",

    time: new Date().toISOString()

};

fs.appendFileSync(

    "logs.txt",

    JSON.stringify(log) + "\n"

);
```

Example Output

```text
{"event":"LOGIN","user":"Rahul","time":"2026-08-08T10:30:00.000Z"}
```

Running the program multiple times adds one JSON object per line.

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs");

try {

    fs.appendFileSync(

        "logs.txt",

        "Application Started\n"

    );

    console.log("Success");

} catch (error) {

    console.log(error.message);

}
```

# Best Practices

✅ Use `try...catch`.

✅ Add `\n` for each new record.

✅ Use `appendFileSync()` only when blocking is acceptable.

✅ Prefer Promise APIs in modern backend applications.

# Common Mistakes

### Using writeFileSync() Instead

```js
fs.writeFileSync(

    "logs.txt",

    "Server Started"

);
```

This replaces the existing file.

If you want to keep previous data,

use

```js
fs.appendFileSync()
```

---

### Forgetting New Line

```js
fs.appendFileSync(

    "logs.txt",

    "Hello"

);
```

Output

```text
HelloHelloHello
```

Better

```js
"Hello\n"
```

---

### Forgetting try...catch

Synchronous APIs throw errors directly.

Always handle them.
