# Introduction

`fs.mkdirSync()` is the synchronous version of `fs.mkdir()`.

It creates a new directory and blocks JavaScript execution until the operation is completed.

If the directory is created successfully, the next line of code executes.

If an error occurs, Node.js throws an exception.

---

# Why mkdirSync()?

Sometimes an application must create required folders before continuing.

Examples

- Creating the `logs` directory before writing logs
- Creating the `uploads` directory during application startup
- Creating build folders
- CLI tools
- Local automation scripts

In these situations, waiting for the directory to be created is completely acceptable.

---

# Syntax

```js
fs.mkdirSync(path[, options]);
```

# Return Value

`fs.mkdirSync()` returns

```js
undefined
```

If the operation fails,

Node.js throws an Error.

# Creating a Directory

Project Structure

Before

```

└── app.js
```

Code

```js
const fs = require("fs");

fs.mkdirSync("uploads");

console.log("Directory Created");
```

After

```
project/

├── app.js

└── uploads/
```

Output

```
Directory Created
```

# Creating Nested Directories

Suppose you want to create

```
uploads/images/profile
```

Code

```js
const fs = require("fs");

fs.mkdirSync(

    "uploads/images/profile",

    {

        recursive: true

    }

);

console.log("Folders Created");
```

Output

```
Folders Created
```

Every missing parent folder is created automatically.

---

# Error Handling

Always wrap synchronous APIs inside

```js
try...catch
```

Example

```js
const fs = require("fs");

try {

    fs.mkdirSync("uploads");

    console.log("Success");

} catch (error) {

    console.log(error.message);

}
```

---

# Recursive Option

Without

```js
recursive: true
```

Code

```js
fs.mkdirSync(

    "uploads/images/profile"

);
```

If

```
uploads/
```

does not exist,

Node.js throws an error.

---

With

```js
recursive: true
```

Node.js automatically creates

```
uploads/

↓

images/

↓

profile/
```

# Best Practices

✅ Use `try...catch`.

✅ Use `recursive: true` for nested folders.

✅ Use synchronous APIs only when blocking is acceptable.

✅ Prefer Promise APIs in modern backend applications.

---

# Common Mistakes

### Forgetting try...catch

`mkdirSync()` throws an error directly.

Always handle it.

---

### Creating an Existing Directory

Trying to create an existing directory without

```js
recursive: true
```

throws an error.

---

### Using mkdirSync() Inside Express Routes

Avoid blocking the event loop.

Use asynchronous APIs instead.
