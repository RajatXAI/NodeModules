# Introduction

`fs.readdirSync()` is the synchronous version of `fs.readdir()`.

It reads all files and folders inside a directory.

JavaScript waits until the directory has been completely read before executing the next line of code.

---

# Why readdirSync()?

Sometimes an application must read a directory before continuing.

Examples

- Reading migration files
- Loading plugins
- Reading configuration folders
- CLI tools
- Build scripts

In these cases, blocking execution is acceptable.

---

# Syntax

```js
fs.readdirSync(path[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | Directory path |
| options | Configuration object |

---

# Return Value

Returns an array.

Example

```js
[
    "image.jpg",
    "notes.txt",
    "video.mp4"
]
```

If the directory cannot be read,

Node.js throws an error.


# Reading Directory Contents

Project Structure

```
project/

└── uploads/

    ├── image.jpg

    ├── notes.txt

    └── video.mp4
```

Code

```js
const fs = require("fs");

const files = fs.readdirSync("uploads");

console.log(files);
```

Output

```js
[
    "image.jpg",
    "notes.txt",
    "video.mp4"
]
```

---

# Reading Nested Directories

```js
const fs = require("fs");

const files = fs.readdirSync(
    "uploads/profile"
);

console.log(files);
```

---

# Error Handling

```js
const fs = require("fs");

try {

    const files = fs.readdirSync("missing");

    console.log(files);

} catch (error) {

    console.log(error.message);

}
```

Output

```
ENOENT: no such file or directory
```

---

# withFileTypes Option

```js
const fs = require("fs");

const items = fs.readdirSync(

    "uploads",

    {

        withFileTypes: true

    }

);

items.forEach((item) => {

    console.log(item.name);

    console.log(item.isFile());

    console.log(item.isDirectory());

});
```

# Best Practices

✅ Use `readdirSync()` only when blocking is acceptable.

✅ Wrap the code inside `try...catch`.

✅ Use `withFileTypes: true` when extra file information is required.

---

# Common Mistakes

### Using readdirSync() inside Express routes

Avoid blocking the event loop.

---

### Forgetting try...catch

`readdirSync()` throws errors directly.

Always handle them.

---

### Assuming Every Item Is a File

Directories are also returned.

Use

```js
item.isFile()
```

or

```js
item.isDirectory()
```

# Key Takeaways

- `fs.readdirSync()` reads a directory synchronously.
- It blocks JavaScript until the operation is complete.
- It returns an array of file and directory names.
- Use `try...catch` because errors are thrown directly.
- It is suitable for startup scripts, CLI tools, and build scripts.
