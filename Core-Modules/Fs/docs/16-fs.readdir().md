# Introduction

`fs.readdir()` is used to read the contents of a directory.

It returns all files and folders present inside the specified directory.

This API is asynchronous, so it does not block JavaScript while reading the directory.

---

# Why readdir()?

Suppose your application stores uploaded files inside

```
uploads/
```

You want to display all uploaded files.

Project

```
uploads/

├── photo1.jpg

├── photo2.jpg

├── resume.pdf

└── notes.txt
```

Using `fs.readdir()`, Node.js can return all these file names.

---

# Syntax

```js
fs.readdir(path[, options], callback);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | Directory path |
| options | Configuration object |
| callback | Function executed after reading the directory |

---

# Callback Function

The callback receives two arguments.

```js
(error, files) => {

}
```

### error

Contains the error if something goes wrong.

Otherwise

```js
null
```

---

### files

An array containing the names of files and folders.

Example

```js
[
    "photo1.jpg",
    "photo2.jpg",
    "resume.pdf"
]
```

---

# Return Value

`fs.readdir()` returns

```js
undefined
```

The directory contents are available inside the callback function.

# Reading Directory Contents

Project Structure

```
project/

└── uploads/

    ├── image.jpg

    ├── video.mp4

    └── notes.txt
```

Code

```js
const fs = require("fs");

fs.readdir(

    "uploads",

    (error, files) => {

        if (error) {

            console.log(error);

            return;

        }

        console.log(files);

    }

);
```

Output

```js
[
    "image.jpg",
    "notes.txt",
    "video.mp4"
]
```

# Error Handling

If the directory does not exist,

Node.js returns an error.

```js
const fs = require("fs");

fs.readdir(

    "missing",

    (error, files) => {

        if (error) {

            console.log(error.message);

            return;

        }

        console.log(files);

    }

);
```

Example Output

```
ENOENT: no such file or directory
```

# withFileTypes Option

Normally,

`readdir()` returns only names.

Example

```js
[
    "image.jpg",
    "notes.txt"
]
```

If you want additional information,

use

```js
withFileTypes: true
```

Example

```js
const fs = require("fs");

fs.readdir(

    "uploads",

    {

        withFileTypes: true

    },

    (error, files) => {

        if (error) {

            console.log(error);

            return;

        }

        files.forEach((file) => {

            console.log(file.name);

            console.log(file.isFile());

            console.log(file.isDirectory());

        });

    }

);
```

Output

```
image.jpg
true
false

notes.txt
true
false
```

# Best Practices

✅ Always handle errors.

✅ Use `withFileTypes: true` when file information is needed.

✅ Validate the directory path before reading.

✅ Prefer Promise APIs in modern applications.

---

# Common Mistakes

### Reading a Missing Directory

Always handle `ENOENT` errors.

---

### Assuming Every Item Is a File

Directories are also returned.

Use

```js
file.isFile()
```

or

```js
file.isDirectory()
```

to check the type.

---

### Ignoring Errors

Never assume the directory exists.
