# Introduction

`fs.existsSync()` checks whether a file or directory exists.

Unlike

```js
fs.access()
```

it does not check permissions.

It simply returns

- `true`
- `false`

Since it is synchronous,

JavaScript waits until the check is completed.

---

# existsSync() vs access()

| Feature | existsSync() | access() |
|----------|--------------|-----------|
| Check Existence | ✅ | ✅ |
| Check Permissions | ❌ | ✅ |
| Returns Boolean | ✅ | ❌ |
| Throws Errors | ❌ | Through callback/Promise |
| Recommended for Permission Check | ❌ | ✅ |

---

# Why existsSync()?

Suppose your application stores uploads inside

```
uploads/
```

Before saving files,

you want to know

```
Does the folder exist?
```

If not,

create it.

---

# Syntax

```js
fs.existsSync(path);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | File or directory path |

---

# Return Value

Returns

```js
true
```

if the path exists.

Returns

```js
false
```

if the path does not exist.

It never throws an error simply because the path is missing.

```js

```

Output


# Creating a Folder If Missing

```js
const fs = require("fs");

if (!fs.existsSync("uploads")) {

    fs.mkdirSync("uploads");

}
```

This is a common startup pattern.

# Best Practices

✅ Use only for simple existence checks.

✅ Good for startup scripts.

✅ Good for CLI tools.

❌ Don't use it before every `readFile()` or `writeFile()`.

---

# Common Mistakes

### Using existsSync() Before readFile()

```js
if (fs.existsSync(file)) {

    fs.readFileSync(file);

}
```

This can create a race condition.

Instead,

read the file directly and handle the error.

---

### Assuming It Checks Permissions

Incorrect.

It only checks whether the path exists.

---

### Using It Inside High-Traffic API Routes

Since it is synchronous,

avoid using it repeatedly inside request handlers.

# Notes

- `existsSync()` is useful for simple existence checks.
- It returns only `true` or `false`.
- It does not check read/write permissions.
- Avoid using it immediately before file operations.
- It is commonly used during application startup.

---

# Key Takeaways

- `fs.existsSync()` checks whether a path exists.
- It returns a boolean value.
- It does not check permissions.
- It is useful for startup scripts, CLI tools, and folder initialization.
- For permission checks, use `fs.access()`.
