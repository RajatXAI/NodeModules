# Introduction

`fs.promises.mkdir()` is the Promise-based version of `fs.mkdir()`.

Instead of using callbacks, it returns a Promise.

This allows us to use `async/await`, making the code cleaner and easier to read.

It is the recommended approach for modern Node.js applications.

---

# Why fs.promises.mkdir()?

Suppose your application starts for the first time.

Before saving uploaded images, it must ensure that the following folder exists.

```
uploads/
```

If the folder is missing,

it should be created automatically.

Using `async/await` makes this process simple and readable.

---

# Syntax

```js
await fs.mkdir(path[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | Directory path |
| options | Configuration object |

---

# Return Value

Returns a Promise.

If the directory is created successfully,

the Promise is resolved.

If an error occurs,

the Promise is rejected.

# Creating a Directory

```js
const fs = require("fs").promises;

async function main() {

    await fs.mkdir("uploads");

    console.log("Directory Created");

}

main();
```

Output

```
Directory Created
```

Project Structure

```
project/

├── uploads/
```

# Creating Nested Directories

Suppose you want to create

```
uploads/images/profile
```

Code

```js
const fs = require("fs").promises;

async function main() {

    await fs.mkdir(

        "uploads/images/profile",

        {

            recursive: true

        }

    );

    console.log("Folders Created");

}

main();
```

Output

```
Folders Created
```

Node.js creates every missing parent folder automatically.

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        await fs.mkdir("uploads");

        console.log("Success");

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

# Best Practices

✅ Prefer Promise APIs in modern Node.js applications.

✅ Use `recursive: true` for nested folders.

✅ Always handle errors using `try...catch`.

✅ Create required directories during application startup.

---

# Common Mistakes

### Forgetting recursive

```js
await fs.mkdir(

    "uploads/images/profile"

);
```

If parent folders do not exist,

Node.js throws an error.

---

### Creating an Existing Folder

If the folder already exists,

Node.js throws an error unless

```js
recursive: true
```

is used.

---

### Forgetting await

```js
fs.mkdir("uploads");

console.log("Done");
```

The directory may not be created before the next line executes.

# Key Takeaways

- `fs.promises.mkdir()` creates directories asynchronously using Promises.
- It works with `async/await`.
- It supports nested directory creation using `recursive: true`.
- It is the preferred API for modern Node.js projects.
- Always handle errors using `try...catch`.
