# Introduction

`fs.promises.rm()` is the Promise-based version of `fs.rm()`.

Instead of callbacks,

it returns a Promise.

This allows us to use `async/await`, making asynchronous code cleaner and easier to maintain.

It can delete

- Files
- Empty directories
- Non-empty directories (using `recursive: true`)

---

# Why fs.promises.rm()?

Suppose your application creates temporary folders while processing uploaded files.

```
temp/

├── image.jpg

├── thumbnail.jpg

└── report.pdf
```

After processing finishes,

the entire folder should be removed.

Instead of deleting every file manually,

Node.js removes the whole directory.

# Syntax

```js
await fs.rm(path[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | File or directory path |
| options | Configuration object |

---

# Return Value

Returns a Promise.

If the operation succeeds,

the Promise is resolved.

If an error occurs,

the Promise is rejected.

The method itself does not return any value.

# Deleting a File

```js
const fs = require("fs").promises;

async function main() {

    await fs.rm(

        "notes.txt"

    );

    console.log("File Deleted");

}

main();
```

# Deleting a Directory Recursively

Project

```
uploads/

├── image.jpg

├── notes.txt

└── profile/

    └── avatar.png
```

Code

```js
const fs = require("fs").promises;

async function main() {

    await fs.rm(

        "uploads",

        {

            recursive: true

        }

    );

    console.log("Directory Deleted");

}

main();
```

Result

```
project/
```

The complete directory tree is removed.

---

# Force Option

```js
const fs = require("fs").promises;

async function main() {

    await fs.rm(

        "temp",

        {

            recursive: true,

            force: true

        }

    );

}
```

If the path does not exist,

Node.js does not throw an `ENOENT` error.

---

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        await fs.rm(

            "uploads",

            {

                recursive: true

            }

        );

        console.log("Deleted");

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

---

# Common Error Codes

| Error Code | Meaning |
|------------|---------|
| ENOENT | Path does not exist |
| EACCES | Permission denied |
| EPERM | Operation not permitted |
| ENOTEMPTY | Directory is not empty (without `recursive: true`) |

# Real Project Example

Suppose an image processing service creates temporary files.

After uploading the final images,

clean up the temporary directory.

```js
const fs = require("fs").promises;

async function cleanup() {

    try {

        await fs.rm(

            "temp",

            {

                recursive: true,

                force: true

            }

        );

        console.log("Cleanup Completed");

    } catch (error) {

        console.log(error.message);

    }

}

cleanup();
```

# Best Practices

✅ Prefer Promise APIs in modern applications.

✅ Use `recursive: true` only when necessary.

✅ Use `force: true` for cleanup scripts.

✅ Always handle errors using `try...catch`.

---

# Common Mistakes

### Forgetting recursive

```js
await fs.rm(

    "uploads"

);
```

If the directory contains files,

the operation fails.

---

### Thinking force Ignores All Errors

Incorrect.

`force: true`

only ignores missing-path (`ENOENT`) errors.

Permission errors and other filesystem errors are still thrown.

---

### Accidentally Deleting Important Directories

Always verify the path before using

```js
recursive: true
```

Deletion is permanent.

---

### Forgetting await

```js
fs.rm(

    "temp",

    {

        recursive: true

    }

);

console.log("Done");
```

The deletion may still be in progress.

# Notes

- `fs.promises.rm()` can delete both files and directories.
- Use `recursive: true` for non-empty directories.
- Use `force: true` for cleanup operations where missing paths are acceptable.
- It returns a Promise and works with `async/await`.
- Always verify the path before deleting recursively.

---

# Key Takeaways

- `fs.promises.rm()` is the recommended API for deleting files and directories in modern Node.js.
- It supports recursive directory deletion.
- It supports `force: true` for cleanup tasks.
- It works seamlessly with `async/await`.
- Always use `try...catch` to handle errors.
