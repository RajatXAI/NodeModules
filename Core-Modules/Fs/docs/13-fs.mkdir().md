# Introduction

Directories (folders) help organize files.

Instead of storing every file in one place, applications create separate folders for different purposes.

Example

```
Project

│

├── uploads/

├── logs/

├── temp/

├── reports/

└── backups/
```

Node.js provides the `fs.mkdir()` API to create directories asynchronously.

---

# Why mkdir()?

Imagine a user uploads an image.

Before saving the image,

your application checks whether the

```
uploads/
```

folder exists.

If it does not exist,

it must be created.

This is one of the most common real-world uses of `mkdir()`.

---

# Syntax

```js
fs.mkdir(path[, options], callback);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | Directory path |
| options | Configuration object |
| callback | Function executed after directory creation |

---

# Callback Function

The callback receives one argument.

```js
(error) => {

}
```

If the directory is created successfully,

```js
error
```

is

```js
null
```

Otherwise,

it contains an Error object.

---

# Return Value

`fs.mkdir()` returns

```js
undefined
```

The result is available inside the callback.

---

# Internal Working

```
Application

↓

↓

libuv

↓

Operating System

↓

Create Directory

↓

↓

Event Loop

↓

Execute Callback
```

JavaScript continues executing while the operating system creates the directory.

# Creating a Directory

```js
const fs = require("fs");

fs.mkdir(

    "uploads",

    (error) => {

        if (error) {

            console.log(error);

            return;

        }

        console.log("Directory Created");

    }

);
```

Output

```
Directory Created
```

Project Structure

```
project/

├── uploads/
```

---

# Creating Nested Directories

Suppose you want to create

```
uploads/images/profile
```

Code

```js
const fs = require("fs");

fs.mkdir(

    "uploads/images/profile",

    { recursive: true },

    (error) => {

        if (error) {

            console.log(error);

            return;

        }

        console.log("Folders Created");

    }

);
```

Output

```
Folders Created
```

Node.js automatically creates every missing folder.

---

# Error Handling

Always handle errors.

```js
const fs = require("fs");

fs.mkdir(

    "uploads",

    (error) => {

        if (error) {

            console.log(error.message);

            return;

        }

        console.log("Success");

    }

);
```

---

# Recursive Option

Without

```js
recursive: true
```

Trying to create

```
uploads/images/profile
```

will fail if

```
uploads
```

does not already exist.

With

```js
recursive: true
```

Node.js creates all missing parent directories automatically.

# Best Practices

✅ Check whether the folder already exists when appropriate.

✅ Use

```js
recursive: true
```

for nested folders.

✅ Handle errors properly.

✅ Prefer Promise APIs in modern applications.

---

# Common Mistakes

### Creating an Existing Folder

Trying to create a directory that already exists (without `recursive: true`) throws an error.

---

### Forgetting recursive

```js
uploads/images/profile
```

cannot be created unless parent folders already exist.

---

### Ignoring Errors

Always check the callback error.

# Key Takeaways

- `fs.mkdir()` creates directories asynchronously.
- It supports nested directory creation using `recursive: true`.
- It is commonly used for uploads, logs, cache, reports, and temporary storage.
- Always handle errors before assuming the directory was created.
