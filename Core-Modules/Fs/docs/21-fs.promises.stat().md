# Introduction

`fs.promises.stat()` is the Promise-based version of `fs.stat()`.

Instead of callbacks, it returns a Promise.

This allows us to use `async/await`, making asynchronous code cleaner and easier to understand.

It returns metadata about a file or directory.

It does **not** read the file contents.

---

# Why fs.promises.stat()?

Suppose your backend receives an uploaded image.

Before processing it, the application wants to verify

- Does the file exist?
- Is it actually a file?
- Is the size less than 5 MB?
- Should the upload be accepted?

Instead of reading the complete file,

Node.js can retrieve only the metadata.

# Syntax

```js
await fs.stat(path[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| path | File or directory path |
| options | Optional configuration |

---

# Return Value

Returns a Promise.

When resolved,

it returns a **Stats** object.

If the path does not exist,

the Promise is rejected.

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        const stats = await fs.stat("missing.txt");

        console.log(stats);

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

Example Output

```
ENOENT: no such file or directory
```

# Real Project Example

Imagine an image upload API.

Before saving the image,

check its size.

```js
const fs = require("fs").promises;

async function validateUpload(filePath) {

    const stats = await fs.stat(filePath);

    const maxSize = 5 * 1024 * 1024;

    if (stats.size > maxSize) {

        throw new Error("File size exceeds 5 MB.");

    }

    console.log("Upload Accepted");

}
```

This pattern is commonly used before storing uploaded files.

# Practical Lab

Project Structure

```

├── app.js
```

app.js

```js
const fs = require("fs").promises;

async function main() {

    try {

        const stats = await fs.stat("image.png");

        console.log("Size:", stats.size);

        console.log("Is File:", stats.isFile());

        console.log("Modified:", stats.mtime);

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

```text
Is File: true

Modified: 2026-08-08T...
```

# Best Practices

✅ Prefer Promise APIs in modern projects.

✅ Always use `try...catch`.

✅ Validate file size before processing uploads.

✅ Use `isFile()` and `isDirectory()` before processing a path.

# Key Takeaways

- `fs.promises.stat()` returns metadata about a file or directory.
- It does not read the file contents.
- It returns a Promise and works seamlessly with `async/await`.
- Use it to validate uploads, inspect files, and build file management features.
