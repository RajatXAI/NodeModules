# Introduction

`fs.promises.appendFile()` is the Promise-based version of `fs.appendFile()`.

Instead of callbacks, it returns a Promise.

This allows us to use `async/await`, making the code cleaner and easier to maintain.

If the file does not exist, Node.js creates it automatically.

If the file already exists, new data is added to the end without removing the existing content.

---

# Why fs.promises.appendFile()?

Suppose your application writes logs.

```
Server Started

↓

User Logged In

↓

Payment Success

↓

Server Stopped
```

Every new event should be added to the same log file.

Replacing the file every time would lose the previous logs.

Appending solves this problem.

# Syntax

```js
await fs.appendFile(file, data[, options]);
```

---

# Parameters

| Parameter | Description |
|-----------|-------------|
| file | File path |
| data | Data to append |
| options | Encoding or configuration |

---

# Return Value

Returns a Promise.

If the operation succeeds,

the Promise is resolved.

If something goes wrong,

the Promise is rejected.

The method does not return the file contents.

# Creating a New File

```js
const fs = require("fs").promises;

async function main() {

    await fs.appendFile(

        "notes.txt",

        "Hello\n"

    );

    console.log("File Created");

}

main();
```

If `notes.txt` does not exist,

Node.js creates it automatically.

---

# Appending JSON Logs

```js
const fs = require("fs").promises;

async function main() {

    const log = {

        event: "LOGIN",

        user: "Rahul",

        time: new Date()

    };

    await fs.appendFile(

        "logs.txt",

        JSON.stringify(log) + "\n"

    );

}

main();
```

Example Output

```text
{"event":"LOGIN","user":"Rahul","time":"2026-08-08T09:30:00.000Z"}

{"event":"LOGIN","user":"Rahul","time":"2026-08-08T09:45:00.000Z"}
```

Each log is stored on a separate line.

# Error Handling

Always use

```js
try...catch
```

```js
const fs = require("fs").promises;

async function main() {

    try {

        await fs.appendFile(

            "notes.txt",

            "Learning Promise API\n"

        );

        console.log("Success");

    } catch (error) {

        console.log(error.message);

    }

}

main();
```

# Best Practices

✅ Prefer Promise APIs in modern Node.js projects.

✅ Use `async/await`.

✅ Add `\n` while writing multiple records.

✅ Always handle errors with `try...catch`.

---

# Common Mistakes

### Forgetting await

```js
fs.appendFile(

    "notes.txt",

    "Hello\n"

);

console.log("Done");
```

The append operation may still be running.

---

### Forgetting New Line

```js
await fs.appendFile(

    "notes.txt",

    "Hello"

);
```

Result

```text
HelloHelloHello
```

Better

```js
"Hello\n"
```

---

### Ignoring Errors

Always wrap Promise-based APIs inside `try...catch`.

# Key Takeaways

- `fs.promises.appendFile()` appends data without removing existing content.
- It creates the file automatically if it does not exist.
- It returns a Promise and works with `async/await`.
- It is commonly used for logs, chat history, audit records, and event tracking.
- Always use `try...catch` to handle errors.
